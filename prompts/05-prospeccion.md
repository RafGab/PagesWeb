# Prompt 05 — Prospección y venta

## Generar mensajes personalizados
```
Eres un vendedor B2B experto en negocios locales. Escribe mensajes para
ofrecer una web nueva a [NOMBRE DEL NEGOCIO] ([SECTOR], [CIUDAD]).

Contexto:
- Problemas detectados en su web: [PEGAR RESUMEN DE LA AUDITORÍA 01]
- Ya les hicimos una versión de muestra: [URL DE LA MUESTRA]
- Nuestra oferta: web lista en 7 días, [PRECIO] + [CUOTA]/mes, garantía:
  [GARANTÍA]

Escribe:
1. WhatsApp inicial (máx. 60 palabras, sin sonar a spam, con la URL y una
   pregunta final de sí/no).
2. Email (asunto + 90 palabras).
3. DM de Instagram (40 palabras).
4. 2 seguimientos (día 3 y día 7), cada uno aportando algo nuevo.
5. Respuestas a objeciones: "es caro", "ya tengo web", "tengo Instagram",
   "mi sobrino me la hace", "déjame pensarlo".
Tono: [tuteo/usted], cercano, concreto. Nada de "espero que estés bien".
```

## Guion de llamada (15 min)
```
Crea un guion de llamada de 15 minutos para cerrar la venta de una web a
[SECTOR] con esta estructura: rapport (1 min) → diagnóstico con preguntas
sobre cuántos clientes nuevos reciben y de dónde (5 min) → enseñar la web
de muestra en pantalla (4 min) → oferta con 3 planos de precio anclando
en el del medio (3 min) → cierre y siguiente paso con pago del 50% (2 min).
Incluye las preguntas exactas.
```

## Propuesta comercial
```
Genera una propuesta de 1 página en HTML imprimible para [NEGOCIO] con:
problema, solución, qué incluye cada plan ([PLANES Y PRECIOS]), plazos,
garantía, forma de pago (50/50) y botón de aceptación por WhatsApp.
```
