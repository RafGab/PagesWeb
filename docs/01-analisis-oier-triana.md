### El método concreto de páginas web (vídeo abril 2026)
*"Cómo vender páginas web con IA a negocios locales y cobrar $3.000 por cliente, usando Claude Code y Google Stitch sin saber programar."*

Resumido:
1. **Nicho**: negocios locales (clínicas, reformas, restaurantes, abogados, talleres…).
2. **Diseño** con **Google Stitch** (genera la UI a partir de un prompt).
3. **Construcción** con **Claude Code** (convierte el diseño en una web real, rápida, con SEO on-page).
4. **Venta** de un proyecto de alto ticket (~$3.000) enfocado a **resultados** (llamadas, reservas, presupuestos), no a "tener una web bonita".
5. **Recurrencia** con mantenimiento / hosting / SEO mensual (modelo Webker).

### Lectura honesta
- **Lo que sí está demostrado**: sabe construir audiencia, sabe empaquetar ofertas y ha operado agencias reales (Ads y Web).
- **Dónde está probablemente el dinero hoy**: en la **formación + afiliación a GoHighLevel**, no solo en la agencia. Es el patrón típico "agency-to-guru": los números grandes vienen de enseñar el modelo.
- **Lo que eso significa para ti**: el *modelo de agencia web* es sólido y replicable (hay decenas de agencias haciendo "web + cuota mensual"), pero **no esperes sus cifras**. Un objetivo realista para empezar solo/a es **3–8 clientes/mes**.

### Por qué el modelo SÍ funciona (independientemente de él)
1. **Coste de producción colapsado**: con Stitch + Claude Code una web que antes llevaba 20–40 h ahora lleva 2–6 h.
2. **Precio anclado en valor**: el negocio local no compra "HTML", compra "más llamadas". El margen es enorme.
3. **Mercado enorme y mal servido**: la mayoría de negocios locales tienen webs lentas, sin móvil, sin SEO local, o solo Instagram.
4. **Recurrencia**: hosting + mantenimiento + SEO local = ingresos mensuales que se acumulan (MRR).

### Riesgos
- Competencia creciente: "webs con IA" ya es un nicho saturado de cursos. **La diferenciación es el nicho + los resultados, no la herramienta.**
- $3.000 es precio de mercado USA/España para webs orientadas a conversión; en LATAM hay que ajustar (ver `02-modelo-replicado.md`).
- Dependencia de herramientas (Stitch está en fase Labs de Google; puede cambiar).
- Si prometes resultados (leads), mide y reporta, o perderás la recurrencia.

**Recomendación**: replicar la parte *operativa* (nicho local → web de conversión hecha con IA → cuota mensual) y **no** la parte de formación. Todo lo necesario está en este repositorio:

- `docs/02-modelo-replicado.md` – oferta, precios, captación, entrega y números.
- `prompts/` – los prompts listos para usar (Stitch, Claude Code, auditoría, prospección, agentes).
